## How to Add Contributors

To add yourself as a contributor to this project, please follow these steps:

1. **Fork** the repository and create a new branch.
2. **Edit** this `CONTRIBUTORS.md` file by adding your name and (optionally) your GitHub profile link in the list below.
3. **Submit a Pull Request** with your changes.

### Example Format

```markdown
- [Your Name](https://github.com/yourusername)
```
